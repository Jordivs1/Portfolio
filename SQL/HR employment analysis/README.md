# HR Employee Attrition - SQL Analysis

## Project Overview
This project analyzes an HR employee attrition dataset using SQL.
The goal is to identify patterns in employee behavior, satisfaction 
and attrition across different departments, job roles and demographics.

## Dataset
- **Source:** Kaggle - IBM HR Analytics Employee Attrition Dataset
- **Records:** 1,470 employees
- **Key columns:** Attrition, Age, Department, JobRole, MonthlyIncome,
  JobSatisfaction, OverTime, BusinessTravel, Education

## Analysis Topics
- Employee attrition distribution
- Salary analysis per department and job role
- Job satisfaction insights
- Overtime and travel impact on attrition
- Demographics analysis (age, gender, education)
- Promotion and career growth patterns

## Tools Used
- SQL (SQLite)
- SQLiteOnline.com

## Key Findings
- Employees who work overtime have a higher attrition rate
- Frequent travelers tend to leave more often
- Lower job satisfaction correlates with higher attrition
